## 💡 The Problem

You use more than one AI coding tool. Maybe Claude Code for deep reasoning, Cursor for rapid iteration, Gemini CLI for quick refactors, Aider for pair programming, Windsurf for flow, GitHub Copilot for autocomplete, and Zed for lightweight editing.

That's seven tools. Seven separate configs. Seven places to maintain the same skills, rules, prompts, and MCP servers.

Every tool speaks its own config language — `CLAUDE.md` here, `.cursorrules` there, `GEMINI.md`, `AGENTS.md`, `CONVENTIONS.md`, `copilot-instructions.md`, `.clinerules`, `.roomodes`, `.windsurfrules`, `.mcp.json` — each with its own format, its own location, its own drift.

Skills go stale in one tool while updated in another. Formats diverge. There is no single place that shows what any given model actually "knows." You're maintaining the same knowledge N times, and every edit is a tax on your focus.

---

## ⚡ The Solution

**Surgical precision. Zero friction.** LLM Neurosurgeon performs a single operation on your machine — then walks away.

1. **Scan** — Discovers every AI tool's configuration across your workspace and home directory. Instantly.
2. **Import** — Ingests skills, agents, rules, memory, prompts, and MCP servers losslessly into **one canonical directory — the Brain** (`~/AIBrain`, backed by Git).
3. **Project** — Projects the Brain back to every tool. Symlinks where tolerated. Generated files stamped with `<!-- GENERATED BY LLM NEUROSURGEON — edit in the Brain -->` where required.
4. **Sync** — A debounced filesystem watcher and OS background schedulers (`launchd`/`systemd`/Task Scheduler) keep everything in lockstep. Edit once in the Brain. Every model stays equally skilled. Forever.

Every sync is a Git commit — a complete **Time Machine** for your AI configuration. Browse history. Diff changes. Roll back any moment.

## ✨ Feature Pillars

| Pillar | What it does |
|---|---|
| 🧠 **The Brain** | One canonical, git-backed directory (`~/AIBrain`). The single source of truth for every model on your machine. |
| 📥 **Universal Import** | Losslessly ingests configs from 12 AI coding tools — each adapter purpose-built for that tool's format. |
| 📤 **Projection Engine** | Per-tool output: symlinks where tolerated, generated files where required, merged JSON/TOML, first-class `AGENTS.md` support. |
| 🔄 **Auto-Sync Daemon** | Debounced filesystem watcher + OS background schedulers. 3-way merge with conflict queue. Every sync = a Git commit. |
| 🛒 **Marketplace Import** | Ingest skills and agents from `anthropics/skills` or any Git repo — with license cards, SHA-256 provenance, and executable script warnings (disabled by default). |
| 🔌 **MCP Hub** | Browse and search MCP servers. Project configs to every tool. Execute stdio/remote health-check handshakes. Store API keys in the OS Keychain via `${VAR}` placeholders. |
| 🩺 **Vitals & Doctor** | Health matrix (tool × capability), drift/broken-link detection, and `neurosurgeon doctor --fix` for one-click repairs. |
| 🛡️ **Safety by Design** | Dry-run defaults. Git snapshot before destructive ops. Checksum verification. Local-first execution. Zero telemetry. |

## 🗂️ Canonical Brain Layout

```text
AIBrain/
├── skills/<slug>/        # SKILL.md + skill.yaml (id, version, triggers, targets, source, sha256)
├── agents/<slug>.md      # Canonical agent definitions (frontmatter: tools, model hints, targets)
├── rules/                # global.md + scoped/<glob>.md (single source for all rules)
├── memory/               # MEMORY.md + topic files
├── prompts/              # Reusable commands / templates
├── mcp/servers/<id>.yaml # Transport, command/url, env-placeholders, targets, health
├── .brain/               # mappings.json (source ↔ canonical ↔ projection + hashes), state.json, locks
└── .git/                 # Git history (the "Time Machine")
```

## 🚀 30-Second Quickstart

### Prerequisites
- **Rust**: 1.75+
- **Node.js**: 20+ (`pnpm` workspace)
- **Git**

### CLI Commands

```bash
# Scan your machine for installed AI tools
cargo run -p neurosurgeon -- scan

# Preview what an import would do (nothing written to disk)
cargo run -p neurosurgeon -- import --dry-run

# Diagnose configuration drift or broken symlinks
cargo run -p neurosurgeon -- doctor

# Auto-repair fixable diagnoses
cargo run -p neurosurgeon -- doctor --fix

# Record a manual Git snapshot of the Brain
cargo run -p neurosurgeon -- snapshot "Updated global rules"

# Roll back Brain state to a prior snapshot
cargo run -p neurosurgeon -- rollback <commit-hash>
```

### Desktop App Setup

```bash
# Build the desktop frontend & launch the Tauri dev window
cd apps/desktop
pnpm install
pnpm tauri dev
```

## 🛡️ Security & Privacy

- **Zero Telemetry**: No tracking, usage analytics, or remote data collection. Ever.
- **Local First**: Every operation — scan, import, project, sync — runs offline on your machine.
- **OS Keychain Secrets**: API keys live in your native OS Keychain. Configuration files reference them as `${VAR}` environment placeholders only.
- **Path Traversal Defense**: All path joins pass through `safe_join()` to block symlink escape and relative path traversal attacks.
