Structure

Grid & Blueprint Framing

A 12-column modular grid (1200px max, 24px gutter) keeps every screen aligned. Cards, panels and terminal windows wear hairline borders with four corner registration marks — square, precise, unrounded. This is the "surgical" half of the identity: never soften it with drop shadows or radius.

Card

Square corners. 1px border. Corner marks at 100% opacity on hover.

Panel

Same framing wraps stat blocks, feature tiles, terminal windows.

Rule

Never round these. Never fill them solid. Line drawings only — the one exception is the primary button.

Voice

Voice & Tone

"Surgical precision. Zero friction." Direct, technical, confident — with exactly one wink (the chain). Never corporate, never cute, never apologetic.

Do

  • Lead with the mechanism: "Every sync is a Git commit."
  • Short declaratives. One idea per sentence.
  • Name real commands and real numbers.
  • Let the product's own output do the talking (terminal blocks, diffs, logs).

Don't

  • Emoji as bullet icons or section markers.
  • Vague superlatives — "revolutionary," "game-changing," "seamless."
  • Generic gradient-blob hero art or stock illustration.
  • Rounded, shadow-heavy cards that could belong to any SaaS product.
