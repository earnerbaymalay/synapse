Command Line Interface
The synapse CLI — automation, scripting, CI
Quick Start
$synapse scan
✓ found 13 adapters on this machine
# preview an import — zero writes
$synapse import --dry-run
would import 7 skills, 6 agents, 0 MCP servers — nothing written
# commit to it
$synapse import
✓ imported into ~/AIBrain
$synapse project
Core Commands
synapse scan
Discover every AI tool installed on this machine
synapse scan [--json]
synapse import
Ingest tool configs losslessly into the canonical Brain
synapse import [--dry-run]
synapse project
Push the Brain back out to every detected tool
synapse project [--dry-run]
synapse sync
Bidirectional sync with 3-way merge and conflict queue
synapse sync [--once | --daemon]
synapse doctor
Diagnose drift and broken links, auto-repair what it can
synapse doctor [--fix]
Time Machine
Snapshot Brain state, or roll back to any prior commit
synapse snapshot "message"
synapse rollback <hash>
Full Loop Example
$synapse sync --daemon
watching ~/AIBrain for changes…
✓ 13/13 adapters synced
# something drifted — ask the doctor
$synapse doctor --fix
✓ 3 issues resolved
# snapshot before a risky change, roll back if needed
$synapse snapshot "before MCP server migration"
✓ a3f8b2c committed
$synapse rollback a3f8b2c
