// QUICKSTART

Get Started in 60 Seconds

Three commands to take complete, permanent control of your AI developer environment.

STEP 01 // SCAN WORKSTATION Read-Only Diagnostic

$ cargo run -p synapse -- scan

Scans home and workspace roots, mapping all 13 supported AI configurations without touching the disk.

STEP 02 // INGEST INTO CANONICAL BRAIN Lossless Ingestion

$ cargo run -p synapse -- import --dry-run

$ cargo run -p synapse -- import

Initializes ~/AIBrain as a local Git repository and snapshots all prompt rules, agents, and MCP servers.

STEP 03 // LAUNCH REAL-TIME AUTO-SYNC Background Watcher

$ cargo run -p synapse -- sync --daemon

Watches the Brain and all tool configs in the background. Changes merge cleanly and create instant Git commits.
